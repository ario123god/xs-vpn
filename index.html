Privacy policy

What the XS-VPN Android app does with information.

Publisher: Ario MonajatiEffective date: November 6, 2026

About this policy

This policy describes information flows identifiable in the current XS-VPN Android project. The app includes the upstream v2rayNG codebase and user-configurable proxy and VPN features. Your use of a selected server is also subject to that server operator’s practices.

Privacy contact: thealangod55@icloud.com.

Information processed on your device

The app stores configuration and preferences locally, including imported server profiles and subscription information, selected and favorite servers, recent servers, connection and test state, app settings, and an optional advertising age band. The age band offers “under 16,” “16 or older,” and “prefer not to say”; it is not a full birth date. App settings and profiles are stored in the app’s local data store. Device backup and uninstall behavior can depend on Android and your device settings.

Some connection, diagnostic, and server-test information is displayed or recorded in app logs. The code does not establish how long external server operators retain logs or whether every connection diagnostic remains only on your device.

Server feed and proxy connections

The app can request a list of XS-VPN server configurations from a configured feed at http://45.83.246.41:8000/api/configs. That request includes a feed authorization token. Because the configured URL uses HTTP, the request and response are not protected by HTTPS in transit; network intermediaries may be able to observe or alter them. The feed operator and network path can receive the device’s IP address and request metadata.

The feed/server implementation and deployment configuration were not present in the project files reviewed. We could not verify whether API access logs record IP addresses, request headers or paths; whether application diagnostics record request data; what log retention or rotation rules apply; or whether a reverse proxy, hosting provider or operating system records requests. Those practices are not confirmed. The feed uses a bearer authorization token, and because it is sent over HTTP it may be exposed to parties able to observe or alter traffic. No claim is made that the feed keeps no logs.

When you connect, your selected server and destination services process traffic routed through the proxy or VPN. Third-party VPN server operators’ logging, IP collection, diagnostic, and retention practices are unknown and are not verified by this policy. Depending on the protocol and destination encryption, a server operator may be able to observe connection metadata and traffic contents. XS-VPN does not control those operators’ practices.

The app can test server connectivity and latency. Some speed tests send test data through a candidate server to Cloudflare’s speed-test service. A test request can expose network metadata, including the server’s exit IP, to Cloudflare. See Cloudflare’s privacy policy.

Advertising and consent

The Play Store build contains the Start.io advertising SDK and a Home banner slot. In the current code, Start.io initialization is fail-closed: the consent-platform and audience-review gates are set to false. The app therefore does not initialize Start.io or request ads. The F-Droid build does not include the Start.io SDK.

The project includes no Google User Messaging Platform (UMP) SDK integration, consent form, consent signal handling, or consent withdrawal flow. The optional age-band choice in the app is not advertising consent. Advertising must remain disabled unless a later version adds and correctly configures the necessary consent and audience handling.

If Start.io is enabled in a future version, Start.io may process information such as IP address, device and operating-system details, advertising identifiers, carrier or device settings, and ad interactions for advertising, measurement, fraud prevention, and related services. The exact data and purposes depend on the SDK and configuration in that release. Review Start.io’s privacy policy and privacy FAQ, and the updated XS-VPN policy and consent choices before using an ad-enabled release.

Other third-party services

The app can contact external services for server configuration, connectivity checks, release information, DNS, IP information, and optional server speed tests. These services receive connection metadata when contacted. Which services are contacted depends on features you use and your settings. Their own privacy policies govern their processing.

Your choices and requests

You can manage or remove locally stored profiles and settings through app controls. You can choose an age band or “prefer not to say”; that choice does not enable ads in the current code. To ask about personal information or request access, correction, or deletion, contact thealangod55@icloud.com. The publisher has not verified feed/server access logging, diagnostics, retention, or third-party VPN operator practices; contact the publisher with questions about those unresolved practices.

Changes

This policy may be updated when app behavior or service providers change. The effective date at the top identifies the version currently posted on this page.
